# NOVA — обзор design/UX-источников

**Дата сводки:** 2026-11-15. Этот документ объединяет пять предоставленных независимых аудитов GitHub-репозиториев. Источники и лицензии ниже описаны в пределах проверок, указанных в этих аудитах; это не повторная юридическая экспертиза, аудит сторонних assets или проверка исполнения кода. Для проектных правил NOVA принципы адаптированы в [`../AGENTS.md`](../AGENTS.md).

## Краткое решение

Все пять репозиториев найдены в предоставленных результатах, у каждого подтверждена лицензия MIT на материалы самого репозитория. Их можно использовать как **информационные design references**, а не как автоматически подключаемые зависимости или утверждённые стандарты NOVA. Ни один не следует рассматривать как готовую реализацию Kotlin/Compose APK или инструкцию по hosting/deploy Next.js. В проект перенесены только общие практики, сформулированные самостоятельно и адаптированные к Android и web. Для внешних шрифтов, изображений, брендинга и связанных материалов права проверяются отдельно. Upstream-команды и скрипты не запускать без независимой проверки.

Источники различаются по назначению. [Taste Skill](https://github.com/Leonxlnx/taste-skill) и [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — реальные agent skills с design/UX guidance; второй прямо содержит рекомендации для Jetpack Compose. [Awesome Claude Design](https://github.com/VoltAgent/awesome-claude-design) — community-каталог примеров дизайн-систем, не executable skill. [Design Motion Principles](https://github.com/kylezantos/design-motion-principles) — agent skill для создания и аудита анимаций. [DESIGN.md Chrome](https://github.com/bergside/design-md-chrome) — Chrome extension и методика описания дизайн-системы. Их применимость к Android варьируется от прямых UX-правил до косвенного шаблона спецификации; к web применимы дизайн, доступность, motion и проектирование токенов.

- **Тип:** Настоящий agent skill с `SKILL.md`, reference-документами, design assets и browser QA-утилитами/finish gate; не просто библиотека UI или каталог.
- **Назначение:** Помогать coding agents создавать и редизайнить прежде всего сайты компаний: формировать визуальное направление, иерархию и цельную систему, выбирать уместные реальные изображения и проверять результат в браузере. Есть reference по web app screens, включая dashboards, формы и состояния данных.
- **Лицензия:** MIT License; файл указывает copyright (c) 2026 Leonxlnx. Лицензия репозитория сама по себе не лицензирует внешние изображения, шрифты и иные assets.
- **Основные материалы:** [README](https://github.com/Leonxlnx/taste-skill), [LICENSE](https://github.com/Leonxlnx/taste-skill/blob/main/LICENSE), [SKILL.md](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md), [app-screens.md](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/references/app-screens.md), [официальная документация](https://www.tasteskill.dev/docs), [история commits](https://github.com/Leonxlnx/taste-skill/commits/main).

- **Применимость к Android:** Ограниченная. Переносимы экранная иерархия, правдоподобные данные, явно определённые состояния и тестирование переполнения; их следует заново оформить для Kotlin/Compose и нативных паттернов. Reference исследован на 23 desktop screens и не включает phone screens. Skill, браузерные scripts, HTML/CSS assets не являются руководством по Compose или APK.
- **Применимость к web:** Высокая для Next.js/React. Предусмотрена работа в имеющемся React/Next.js без смены стека, несколько viewport и браузерная инспекция. Упоминание Next.js static export не делает репозиторий инструкцией по hosting.
- **Переносимые практики NOVA:** исходить из задачи и аудитории продукта, а не универсального шаблона; назначать каждому экрану один основной вопрос и действие; поддерживать согласованность данных/показателей; проектировать empty, zero, loading и error; учитывать реальные размеры, переполнение и доступность; сохранять работающие маршруты и поведение при изменении внешнего вида; проверять экранные состояния и на Android, и в браузере.
- **Ограничения и риск копирования:** README требует Node.js 22+ и Chrome/Edge/Chromium для скриптов. Проверенные материалы не описывают сборку APK, публикацию приложения или хостинг сайта. Не копировать/исполнять scripts и инструкции без отдельного аудита. Не считать лицензии сторонних assets покрытыми MIT.

- **Применимость к Android:** Высокая для дизайн-решений: README прямо указывает Jetpack Compose; правила описывают 48dp hit area, safe areas/system bars, ритм 4/8dp, нативную семантику, обратную связь, screen-reader/focus order, темы и крупный системный текст. - **Ограничения и риск копирования:** Нет инструкций для сборки, подписи или выпуска APK и нет hosting/deploy руководства. Не требуется запускать skill CLI, чтобы использовать проверенные идеи. Не запускать installer/скрипты без анализа содержимого и последствий; лицензии сторонних шрифтов, иконок и внешних ресурсов проверять отдельно.

Не запускать/копировать их без отдельного аудита. Автоматически извлечённые токены — черновые наблюдения, не подтверждённый NOVA brand spec и не гарантия WCAG/accessibility. Не предполагать, что TypeUI является стандартом Android или React.

## Правило применения к NOVA

Ссылки выше — исследовательские источники, а не adopted dependencies. Инструкции по дизайну в [`../AGENTS.md`](../AGENTS.md) являются самостоятельными правилами NOVA и сохраняют существующие пользовательские требования к палитре `#101722` / `#70E1C1` и бренду N. Перед добавлением внешней библиотеки, шрифта, иконки, изображения, скрипта или существенного фрагмента кода нужно отдельно проверить источник, лицензию, безопасность и соответствие Android/web. Ни один из пяти репозиториев не найден отсутствующим; по переданным аудитам у всех пяти указана MIT-лицензия на repository materials.

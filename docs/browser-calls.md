# Аудио- и видеозвонки в NOVA

Личные аудиозвонки работают между открытыми клиентами NOVA Web и Android. Видеозвонки доступны между веб-клиентами с поддержкой WebRTC. Браузеру требуется HTTPS для доступа к микрофону и камере, за исключением localhost в разработке. Клиенты запрашивают разрешение при исходящем звонке или принятии входящего. На Android звонок завершается при сворачивании приложения.

## Сигналы и маршрутизация

Клиенты подписываются на звонки с помощью `call:ready` на авторизованном Socket.IO-соединении. Веб отправляет `{}`, Android отправляет `{ "audioOnly": true }`. `call:start` принимает ID личного чата и тип звонка. Сервер проверяет членство и отправляет `call:invite` доступным клиентам собеседника, которые поддерживают этот тип звонка. После `call:accept` один конкретный сокет получает право обмениваться SDP и ICE через `call:signal`. Завершение и отказ передаются через `call:end`. При отключении участника звонок завершается.

Медиа передаётся по WebRTC напрямую либо через TURN. NOVA API передаёт сигнализацию и не записывает медиа. Звонки пока используют один процесс Socket.IO. Для нескольких реплик нужны общий реестр звонков и совместимый адаптер Socket.IO. Сервер проверяет сессию при подключении сокета. Штатный выход из веб-клиента закрывает сокет сразу, а отзыв сессии через REST сам по себе не закрывает ранее подключённый сокет.

## Связь между сетями

Задайте в окружении API `CALL_STUN_URLS` и `CALL_TURN_URLS` со списком URL через запятую. Для coturn включите `use-auth-secret` и установите одинаковое закрытое значение на стороне coturn и API (`CALL_TURN_SECRET`). После проверки участников API выдаёт клиентам временные учётные данные TURN. Максимальная длительность звонка составляет 3 часа, срок учётных данных покрывает её с запасом. Для выхода в интернет рекомендуется проверить TURN по UDP и TLS/TCP и ограничить ретрансляцию в закрытые сети средствами coturn.

Без настроенных STUN/TURN звонок зависит от того, смогут ли клиенты установить прямое соединение. Входящие звонки доставляются при открытом подключении NOVA. Фоновые push-уведомления о звонках и групповые звонки потребуют отдельных интеграций.

Android использует нативную библиотеку WebRTC `io.github.webrtc-sdk:android:150.7871.08` из Maven Central. В APK включены уведомления о лицензиях WebRTC и пакета сборки. [Android WebRTC SDK](https://github.com/webrtc-sdk/android/releases/tag/v150.7871.08)

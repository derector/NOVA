Как установить NOVA

  1. Скачайте APK

    Сохраните подписанный файл с этой страницы.

  2. Откройте файл

    Android запустит установщик. Если система спросит разрешение, разрешите установку для браузера или файлового менеджера, из которого открыли APK.

  3. Создайте аккаунт

    Откройте NOVA, подтвердите адрес электронной почты и выберите имя пользователя.

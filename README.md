# PRISM / Motion Lab

Independent static demo of procedural material, motion, and interaction design. No connection to any existing product or repository. No external dependencies or analytics.

Open `index.html` in a browser or run `python -m http.server 8080` from this directory. Supports three color palettes, glow intensity, animation pause, light/dark theme, expandable detail cards, keyboard controls, responsive layouts and reduced motion.

The visual design uses general techniques from the agent toolkit catalog; it does not claim that third-party skills or UI packages are installed. The demo uses native HTML/CSS/JS.
